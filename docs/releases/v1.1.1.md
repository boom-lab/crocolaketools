Bug-fix release. No change to the data product or to the configuration format.

## Fixed

- `parse_yaml_argo_gdac.sh` (used by the Argo GDAC jobs to read `input_path`
  and `outdir_pq` of `ARGO-GDAC_PHY`/`ARGO-GDAC_BGC`) prefixed absolute paths
  with the configuration directory, e.g. `/srv/mirror` became
  `<config-dir>/srv/mirror`. Jobs using absolute paths in `datasets.yaml`
  downloaded the GDAC mirror and wrote parquet output under the configuration
  directory. Absolute paths are now used as they are; relative paths still
  resolve against the configuration directory, as in the Python code.
- A missing `input_path` or `outdir_pq` for an `ARGO-GDAC_*` entry is now an
  error, instead of resolving to `<config-dir>/null`.

## Upgrading

Deployments with absolute `ARGO-GDAC_*` paths in `datasets.yaml` should
upgrade and not run the Argo GDAC jobs with v1.1.0. Check for a stray copy of
the mirror under the configuration directory.
