Bug-fix release. No change to the data product or to the configuration format.

## Fixed

- `merge_crocolake --config` passed the CrocoLake path to
  `crocolakeloader.Loader` as a `pathlib.Path`, which v1.1.x returns from the
  configuration. The loader joins `db_rootpath` to strings with `+`, so the
  PHY and BGC merges failed at start-up with
  `TypeError: can only concatenate str (not "PosixPath") to str`. The path is
  now converted to a string before it reaches the loader.

## Testing

- New `tests/test_merge_crocolake.py` runs `merge_crocolake()` against a
  stand-in loader that handles `db_rootpath` the same way, and is part of the
  downloader/config CI job.

## Upgrading

Deployments running the merge with v1.1.0 or v1.1.1 should upgrade; no
configuration changes are needed.
