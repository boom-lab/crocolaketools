Bug-fix release for `download_spraygliders` and `spray2parquet`. No change to
the data product, the configuration format or the local Spray filenames.

## Fixed

- `spray2parquet` failed with `TypeError` on chunks whose times are all NaT
  (xarray >= 2025.1.2). Any `chunk_profile` small enough to produce such a
  chunk was affected; the default, 5000, avoided it on current data.
- A failed `spray2parquet` run left `tmp_path` behind, blocking the next run.
  It is now removed, unless it existed before the run started.
  `cleanup()` no longer removes empty parent directories of `tmp_path`.
- `download_spraygliders` skipped `FLEAT.nc`, `Calypso.nc` and `OKMC.nc`
  (renamed on the server) and never downloaded `mab_swot.nc`. Remote names
  are now read from the ERDDAP listing.
- `download_spraygliders` now re-downloads files whose size or modification
  time changed on the server, and exits with status 1 if any dataset fails.

## Added

- `download_spraygliders` warns about server datasets missing from
  `SPRAY_FILES`. `--files` also accepts dataset IDs.

## API changes

- `SPRAY_FILES` maps dataset ID to local filename.
- `download_spraygliders()` returns `(paths, failed)`.
- `DownloaderSprayGliders.get_url()` takes a dataset ID.

## Upgrading

Remove any `tmp_path` left by a failed v1.1.3 run before the first v1.1.4 run.
